# lineage-first-credit-bench

Open reference implementation and benchmark of lineage-first ingestion for multi-tenant credit data. Two ingestion designs (a per-integration audit-log baseline and a lineage-first design with an independent, append-only lineage substrate) run against the same synthetic workload, and the benchmark measures integration cost, audit replay, tenant isolation, and alternative-data fault escape.

All data is synthetic and generated by seeded code in this repository; see [DATA_SPEC.md](DATA_SPEC.md).

## Quick start

```bash
docker compose up -d db
npm ci
npm test
```
